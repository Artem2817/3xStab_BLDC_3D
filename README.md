# Подвес FPV-камеры

Проект трёхосевого подвеса FPV-камеры, выполненный в Autodesk Inventor.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `Gimbal.iam` | Главная сборка подвеса |
| `КамераФПВ.ipt` | Модель FPV-камеры |
| `CAM.ipt` | Деталь крепления камеры |
| `CAM_Hand.ipt` | Рычаг крепления камеры |
| `BLDC_Gimbal+Enc.ipt` | BLDC-мотор подвеса с энкодером |
| `BLDC_Hand_1.ipt` | Первый рычаг крепления мотора |
| `BLDC_Hand_2.ipt` | Второй рычаг крепления мотора |
| `OldVersions/` | Предыдущие версии файлов, сохранённые Autodesk Inventor |

## Как открыть

1. Клонируйте репозиторий, сохранив его структуру каталогов.
2. Откройте `Gimbal.iam` в Autodesk Inventor.
3. Если Inventor запросит расположение компонентов, укажите корневую папку проекта.

Все актуальные компоненты сборки находятся в корне репозитория. Файлы из `OldVersions/` нужны только для восстановления и не должны использоваться в основной сборке.

## Работа с проектом

- Перед изменением деталей создавайте отдельную ветку Git.
- После правок откройте `Gimbal.iam` и убедитесь, что все ссылки разрешены, а сборка перестраивается без ошибок.
- Коммитьте изменённые CAD-файлы вместе, если они относятся к одной ревизии сборки.
- Не редактируйте файлы в `OldVersions/` вручную: этой папкой управляет Autodesk Inventor.

Файлы Inventor имеют бинарный формат, поэтому Git не может корректно объединять параллельные изменения одной и той же детали. Согласовывайте такую работу заранее.
